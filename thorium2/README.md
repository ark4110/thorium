# Thorium 2

Нестационарный радиационно-кондуктивный тепловой расчёт по конечно-элементной модели. Новая
реализация подхода T.H.O.R.I.U.M. 1 (диссертация А. Ю. Шаенко, ФИАН, 2011): один конечный
элемент — один тепловой узел, излучение методом Монте-Карло. Ошибки первой версии исправлены,
схема интегрирования заменена на неявную.

Входные данные те же, что у первой версии: модель NASTRAN `*.bdf` и файл свойств `*.top`
(формат — руководство T.H.O.R.I.U.M., глава 4). Результаты пишутся в текстовом формате первой
версии. Расчёт идёт на CPU, видеокарта не нужна.

## Сборка и запуск

Нужны компилятор C++20, CMake ≥ 3.20, Eigen 3.4 и GoogleTest (для тестов); OpenMP — по желанию.

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/thorium2_tests          # все тесты
./build/thorium2 model.bdf      # рядом должен лежать model.top
```

Без прав администратора инструменты ставит `scripts/setup-toolchain.sh` (micromamba), после
него — `. scripts/env.sh`. Сборка с санитайзерами: `-DTHORIUM2_SANITIZE=ON`.

### Ключи программы

```
thorium2 [ключи] MODEL.bdf
  --top FILE       файл *.top (по умолчанию — с тем же именем, что модель)
  --out FILE       результаты в формате первой версии (по умолчанию MODEL.txt)
  --balance FILE   баланс мощности модели и статистика решателя по шагам
  --every N        писать каждый N-й шаг (первый и последний — всегда)
  --end T          закончить в момент T вместо t_START + t_LENGTH
  --steps N        сделать N шагов
  --photons N      пучков фотонов на грань за шаг (по умолчанию N_PH из I_PARAM)
  --seed S         зерно генератора (тот же S — тот же результат)
  --threads N      потоков (по умолчанию — сколько процессоров доступно процессу)
  --check          только прочитать и проверить модель
```

Код выхода: 0 — успех, 1 — ошибка во входных данных или ключах (с файлом и строкой),
2 — сбой расчёта (результаты до момента сбоя сохраняются).

### Формат результатов

Как `output_txt` первой версии (`Form1.Save_txt_results`):

```
Element_number Time,s Temperature,K  Input_heat_power,W
1 0 300 0
1 10 300.123457 1.5
...
2 0 300 0
```

Строки сгруппированы по элементам, внутри — по времени; значения округлены до 6 знаков, разделитель
дробной части — точка, концы строк CRLF. `Input_heat_power` — суммарная мощность, подводимая к
элементу (теплопроводность + излучение + источники) в конце шага; в начальный момент 0, как в
первой версии. Файл пишется после окончания расчёта.

## Что поддерживается

**`*.bdf`**: `GRID` (базовая система координат), `CTRIA3`, `CQUAD4`, `CTETRA`, `CPENTA`, `CHEXA`
(у `CTRIA6`, `CQUAD8`, `CTETRA10`, `CPENTA15`, `CHEXA20` берутся угловые узлы, с предупреждением),
`PSHELL` (толщина, NSM), `PSOLID`, `MAT1`/`MAT4` (плотность). Малые, большие (`*`) и свободные
(через запятую) поля, продолжения, табуляции. Элементы и карточки, которые изменили бы тепловую
модель, но не моделируются (`CBAR`, `CROD`, `RBE2`, `PCOMP`, `CORD*`, …), — ошибка, а не пропуск.

**`*.top`**: `FTOP`, `MEDIUM1`, `DEPEND`, `RSOURCE1`, `HSOURCE1`, `T_ALL`, `T_INIT`, `T_SET`,
`G_MEDIUM`, `I_PARAM`. Неизвестная карточка — ошибка.

Не поддерживается (ошибка с указанием места): излучение с заданным спектром (`CDF`, `T_eff`),
зависимость свойств от частоты, углов и случайного числа; системы координат; композиты.

## Физика и отличия от первой версии

| | Первая версия | Thorium 2 |
|---|---|---|
| Проводимость между элементами | арифметическое среднее λ по (2.26), к тому же обе λ брались из материала соседа | последовательные сопротивления: `G = A / (lᵢ/λᵢ + lⱼ/λⱼ)`, `l` — по нормали к общей грани |
| Стык трёх и более оболочек на одном ребре | попарно | точное исключение общего узла («звезда»): `qₐ = gₐ (Tⱼ − Tₐ)`, `Tⱼ = Σ g T / Σ g` |
| Оболочки по ребру | площадь контакта по меньшей толщине | любой угол между оболочками; у каждой половины своя толщина |
| Оболочка на грани объёмного элемента | — | тепловой контакт, закрытые стороны не излучают |
| c(T) | баланс по `c(T)·T` | баланс по энтальпии `H(T) = ∫c dT` |
| Таблицы `DEPEND` | метод обратных расстояний | кусочно-линейная (T или t) и билинейная (T, t) интерполяция; аргументы позиционные, как в руководстве |
| Интегрирование | явные Эйлер / Адамс, сглаживание | неявная BDF2 + метод Ньютона, T⁴ неявно; устойчиво при любом шаге |
| Излучение | OpenGL, 1 пиксель | трассировка лучей по BVH, Ламберт, поглощение / диффузное / зеркальное отражение / пропускание |

Типы интеграторов первой версии (`EULER`, `EULER_V`, `ADAMS_4`) в `I_PARAM` принимаются и заменяются
на BDF2 с шагом `t_STEP`, о чём выводится предупреждение; `K_T_min`, `K_T_max` и сглаживание не нужны.

Излучение: на каждом шаге каждая излучающая грань испускает `N_PH` пучков; получаются доли
`F(f→e)` её излучения, поглощённые элементами. Мощность грани `ε σ A T⁴` берётся при новой
температуре, поэтому связь через T⁴ решается неявно. Внешние источники `RSOURCE1` — изотропные
точки; их пучки посылаются только в конус, содержащий модель. Результат не зависит от числа потоков.

## Проверка

`./build/thorium2_tests` — около 90 тестов, среди них:

- угловые коэффициенты против каталога Хауэлла (формулы 3.1–3.2 диссертации), 25 конфигураций, допуск 4σ;
- зеркало (коэффициент до изображения на 2c), пропускание, взаимность Гебхарта в сером кубе,
  внешний источник и тень;
- второй порядок BDF2, сохранение энергии в замкнутой полости, устойчивость при шаге ×10⁴ от явного предела,
  точная энтальпия при c(T);
- раздел 3.2 диссертации: рис. 3.7, 3.9, 3.11, 3.16 (пластины), 3.28 (стержень из 100 CHEXA),
  3.30 (медная пластина 10×10, сходимость второго порядка к непрерывному решению);
- все четыре модели примеров первой версии (`tests/data/v1_examples`) читаются и считаются.
